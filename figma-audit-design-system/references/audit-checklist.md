# Audit Checklist

Review the design system top-down.

## 1. Category level

- Does each category title match the specs below it?
- Are components grouped by function rather than by page?
- Are category titles positioned consistently at the top of the group?

## 2. Spec level

- Is `Title` above `Canvas`?
- Is `Canvas` below `Title`?
- Does the spec title match the displayed instance or component set?
- Is the canvas using the expected auto layout and padding format?

## 3. Instance level

- Does the canvas contain the correct component or component set?
- If variants exist, is the whole component set displayed when appropriate?
- Are nested instance names semantic where needed?

## 4. Naming level

- Are there duplicate visible titles for different components?
- Are component names unique?
- Are category titles, spec titles, and component names aligned?

## 5. Layer naming level

- Are generic names like `Frame 12` gone?
- Are key role layers semantic?

## 6. Source screen usage

- Is the target screen actually using design system instances?
- Which raw areas still need extraction or rebinding?
